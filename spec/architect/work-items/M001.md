## Objective

Formally adopt Architecture 1.1 as the forward normative architecture and
freeze its locks, successor Work Item contracts, dependency graph, migration
classifications and vertical-proof boundaries while preserving Architecture
1.0 history (roadmap gate `M001_ARCHITECTURE_1_1_FREEZE`).

## Deliverable (single governance-classified PR)

1. **ACR acceptance** — `spec/acr/ACR-014-architecture-1.1-freeze.md` flips to
   ACCEPTED with all eight change-control elements complete and the
   resulting Architecture Version 1.1 recorded.
2. **Successor snapshots promoted** — `spec/architecture.md` and
   `spec/architecture-lock.md` carry Architecture 1.1 semantics and
   LOCK-101..LOCK-120 as FROZEN.
3. **Historical archive** — the Architecture 1.0 snapshot (architecture,
   locks, work-item registry, dependency graph) is preserved verbatim under
   `spec/history/` with an explicit supersedence chain; no historical record
   is rewritten or deleted.
4. **Successor registry canonical** — the M001–M014 registry and successor
   dependency graph become the canonical forward contracts; the 1.0
   registries are preserved as history.
5. **Accepted-proposal records** — the 1.1 package documents carry ACCEPTED
   status headers pointing at the canonical successor files.
6. **Synchronized governance updates** — AGENTS.md, README.md, roadmap
   (v1.7: M001 COMPLETE, R7 next unlocked), execution-state, execution
   ledger, current-state projection, and the current-governance checkers
   (`tools/current_spec_check.py`, `tools/fresh_session_check.py`) all
   validate the post-freeze state and fail closed on pre-freeze markers.
7. **Evidence** — `docs/M001-evidence.md` records the verification matrix:
   every gate run, its result, and the exact delivery head.
